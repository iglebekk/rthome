# Laravel Valet

This project runs through Laravel Valet at `http://rthome.test`.

- Use the Valet URL for manual browser verification.
- Do not start `php artisan serve` for this project.
- Pest browser tests may use their framework-managed test server for test isolation and `actingAs()`; this does not replace Valet for manual verification.
